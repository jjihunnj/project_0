# Погода — Weather App

Учебный проект: сайт прогноза погоды с использованием публичного API.

## Описание

Сайт показывает текущую погоду по любому городу.  
Используется **wttr.in** — бесплатный сервис погоды без API-ключа.

### Возможности
- Поиск города (русский / английский)
- Температура и «ощущается как»
- Описание погоды + иконка
- Влажность, ветер, давление, видимость
- Цветной современный дизайн
- Адаптивная вёрстка

## Технологии
- HTML5
- CSS3 (градиенты, glass-эффект, анимации)
- JavaScript (Fetch API)
- wttr.in API

## Структура проекта

```
├── index.html      # Разметка
├── style.css       # Стили
├── script.js       # Логика + API
└── README.md       # Этот файл
```

## Как запустить

1. Скачай все файлы в одну папку
2. Открой `index.html` в браузере

Никаких ключей и установок не требуется.

## API

Сервис: [wttr.in](https://wttr.in/)

Пример запроса:
```
https://wttr.in/Bishkek?format=j1&lang=ru
```
